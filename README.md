# E-Commerce Tech

Progetto scolastico della classe **5BI** (a.s. 2026/2027).

Sito web statico di una singola pagina che simula una scheda prodotto per il laptop **Lenovo ThinkPad X380 Yoga**, con header, descrizione, tabella specifiche tecniche, bottone "Aggiungi al carrello" e form per lasciare una recensione.

## Tecnologie

- HTML5
- CSS3 (variabili CSS, flexbox)
- Nessun JavaScript

## Struttura

- `index.html` — pagina principale.
- `style.css` — fogli di stile.

## Note

Il progetto è stato realizzato a scopo didattico. Le immagini e i dati dei prodotti sono di esempio.
